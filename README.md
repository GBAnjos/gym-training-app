# Vida - Gym & Life Planner

> Estrutura real. Vida real.

Personal life planning app with gym tracking, meal planning, and weekly schedule management.

## Features

- **Weekly Schedule**: Day-by-day timeline with customizable office/home days
- **Gym Training**: Full workout tracker with weight logging, sets/reps, and progress history
- **Meal Planning**: Structured meal plan with macro targets for muscle gain
- **Progress Tracking**: Weight log with visual progress toward 80kg goal

## Tech Stack

- React 18 + Vite
- Supabase (Auth + Database)
- Chart.js
- CSS Custom Properties (no frameworks)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Automatic deployment to GitHub Pages via GitHub Actions on push to `main`.
